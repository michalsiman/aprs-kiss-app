APRS & Packet

APRS a packet rádio přes KISS TNC (Quansheng UV-K5 s firmwarem F4HWN)

Instalace

Klikněte na tlačítko, soubor otevřete ve Správci aplikací a potvrďte instalaci. Nové verze pak přijdou samy, spolu s ostatními aktualizacemi.

Nainstalovat

Nebo v terminálu:

flatpak install https://michalsiman.github.io/aprs-kiss-app/aprs-kiss.flatpakref

Potřebujete Flatpak (v Linux Mintu je už v základu). Při první instalaci se z Flathubu stáhne i prostředí GNOME, pokud ho ještě nemáte.

Install (English)

Click the button, open the file in your software manager and confirm. New versions then arrive with your other updates.

Install 
flatpak install https://michalsiman.github.io/aprs-kiss-app/aprs-kiss.flatpakref
